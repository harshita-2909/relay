# Project Conventions
- Stack: Node.js (Express) backend, React frontend, SQLite database.
- Execution: All execution must be fully local with no external services or APIs.
- Goal: Implement Part A (Core Features) of the Relay product brief.
- Workflow: Explore, plan, implement, and verify step-by-step.
- Code Rules: Keep components functional, use structured JSON for API payloads, and ensure clean separation between the Chirp app simulation and the Relay engine.
